# Sales Data Analysis and Visualization Dashboard

A data analytics project that uses Python, SQL, Excel, and Power BI to explore sales data and present business trends through an interactive dashboard.

## Overview

The project is organised around a practical analytics workflow:

1. Prepare and clean the sales data using Python.
2. Query and analyse the data with SQL.
3. Use Excel and Power BI to support analysis and visual reporting.
4. Present sales trends and findings in a dashboard.

## Technology

- Python
- SQL
- Microsoft Excel
- Power BI

## Repository structure

```text
.
├── python/     # Python analysis scripts
├── sql/        # SQL queries
├── data/       # Dataset and reports
└── powerbi/    # Power BI dashboard files
```

## Getting started

1. Clone the repository:
   ```bash
   git clone https://github.com/harshabeduduri/Sales-Data-Analysis-Dashboard.git
   cd Sales-Data-Analysis-Dashboard
   ```

2. Explore the folders:
   - Start with `python/` for the data-processing scripts.
   - Review `sql/` for the analysis queries.
   - Check `data/` for the project data and reports.
   - Open the relevant dashboard file in `powerbi/` using Power BI Desktop.

## Analysis focus

- Data cleaning and preprocessing
